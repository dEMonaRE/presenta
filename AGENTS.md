# AGENTS

This repository stores presentation decks and supporting assets in per-deck folders. All topics must have folder and its link will be in readme and must compatiable with Marp vscode.

## Conventions

- Keep each deck in its own folder under the repo root.
- Use a descriptive folder name, e.g. `copilot-lens/`.
- Keep the deck markdown and any local image assets together in that folder.
- Keep the root README minimal: list the deck links and the Marp setup prerequisites only.
- Do not add build tooling or package manifests unless explicitly needed for a presentation.

## Example

```text
presenta/
  README.md
  AGENTS.md
  copilot-lens/
    copilot-lens-lt.md
    copilot-lens-hero.png
```
